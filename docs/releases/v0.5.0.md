# MorningstarModbusAPI v0.5.0

v0.5.0 is a feature release built on the v0.4.0 controller-first telemetry baseline.

## Highlights

- Adds a persistent system/site layer above immutable `controller_uid` identities.
- Adds normalized multi-controller metrics and history with explicit `complete`, `partial`, and `empty` quality.
- Adds system energy, health, topology, event timeline, and SSE streaming surfaces.
- Adds a retained-history provider registry so verified controller logger backends remain separate from raw Modbus poll history.
- Adds optional inbound SNMP trap event ingestion without introducing SNMP writes or active control.
- Expands source-backed GenStar logger/fault/alarm/energy coverage.
- Reorganizes the Python runtime into domain-oriented packages for API, transports, protocol, controllers, history, persistence, polling, systems, runtime orchestration, capture, and SNMP.
- Removes the pre-release flat-module compatibility layer and canonicalizes imports to owning domain packages.

## Compatibility and safety

The service remains read-only: Modbus write-register, write-coil, reset, equalize, EEPROM mutation, and generic raw-command surfaces are not introduced. The pre-release flat Python import paths are intentionally removed in this version; all repository and external code must import from the canonical package paths documented in `docs/package-layout.md`.

## Upgrade notes

No destructive database migration is required. Install the new version normally and keep existing configuration; new `[system]` and `[snmp]` settings are optional/default-safe. Applications can continue using controller/device APIs or adopt `/v1/systems` incrementally.
